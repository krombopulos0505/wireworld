# Wireworld
cellular automaton

## Download and Run
```bash
git clone https://github.com/krombopulos0505/wireworld.git
cd wireworld
cargo build --release
./target/release/wireworld
```

## How to Play
. - to delete any cell  
c - to put conductor  
v - to put electron head  
b - to put electron tail  
h, j, k, l - are movement keys
